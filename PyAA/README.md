# Using the PyAA Association Analysis Notebooks
This document is a basic walkthrough of the various ipython notebooks focused in association analysis. The folder also consists of a modified version of the efficient apriori algorithm.


## Navigation

- `playingAroundWithDataset/` This contains my first attempts at exploring the contents of the NASA Exoplanet Archive

- `AssiciationAnalysis/` This contains my first attempt at using the apriori algorithm to generate high confidence rules. The file also contains my attempts at incorporating duplicates into the algorithm, filtering the dataset duplicates, and graphing confidence and lift before and after using the duplicate method.

- `StatisticDistribution/` This was the other path that I originally explored. It goes through my attempts at creating simulation of possible universes using error. It also tracks the persistence of certain rules throughout different simulations.
    
- `CombinedMethods/` When I first began the project, there were two main paths that I explored. First, there was creating the duplicate method found in AssociationAnalysis. Second, I wanted to run simulations on the error in the dataset. This file combines both paths into one file.

- `RuleAnalysis/` I test the persistence of certain rules in simulations. Additionally, I incorporate resillience into the new methods of testing the strength of rules.
- `testingRules/` I wanted to look at the proportion of times that using only n% of the data will generate rules to predict the remaining 1-n% of the data. Compared the rules generated by n% of the data with rules generated by the other 1-n%.

- `numericalValues/` This is my code for testing the new algorithm that is able to incorporate numerical values instead of just categorical data. Statistical tests are ran on various binning methods to test for efficiency.

- `findingSystems/` This uses the association analysis processses from the other files and finds actual systems throughout the database that match the LHS of the rule.

- `doubleCheckingMyWork/` This is a dummy file that I occasionally used to test code when other files were too clustered and unorganized. 

### PSCompPars

This is the most current NASA Composite Exoplanet Archive as of June 12th, 2025.

### Everything Else

All other files are an adapted version of the efficientApriori algorithm. This was mostly to be able to incorporate numerical values directly into the algorithm for ease.

__The minsupport file was a test to incorporate a more significant support value for each value of k. It does not work. Make sure that the algorithm does not call this file during general use.__
  
Not all files in use the modified algorithm. Some just call the efficientApriori algoritm.
